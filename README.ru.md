# Shopware 6 Reorder & Product Insights

[English](README.md) | [Deutsch](README.de.md)

Плагин для Shopware 6, который связывает товары с историей заказов, отображает аналитику покупок в профиле клиента и карточке товара в админке, а также включает быстрый повторный заказ в Storefront.

## Возможности

- **Заказы в карточке товара (Админка):** просмотр всех заказов, содержащих конкретный товар, прямо в деталях товара с указанием количества и цены за единицу.
- **Купленные товары в профиле клиента (Админка):** сводный список всех уникальных товаров, приобретенных клиентом.
- **Мои покупки и повторный заказ (Storefront):** позволяет покупателям быстро просматривать и повторно заказывать ранее купленные товары из личного кабинета.
- **Гибкая настройка:** возможность независимо включать или отключать отображение каждого из трех блоков через настройки плагина.
- **Переводы:** Английский, Немецкий и Русский.

## Требования

- Shopware `~6.7.0`
- Проверено на Shopware 6.7.15.1 и PHP 8.4

## Установка

Скомпилированные ассеты административной панели **не входят** в состав репозитория, поэтому после установки необходимо пересобрать админку.

1. Перейдите в директорию плагинов вашего проекта Shopware:
   `cd custom/plugins`

2. Клонируйте репозиторий в папку `ModestoxReorderInsights`:
   `git clone https://github.com/Modestox/shopware-reorder-insights.git ModestoxReorderInsights`

3. Установите и активируйте плагин:
   `bin/console plugin:refresh`
   `bin/console plugin:install --activate ModestoxReorderInsights`

4. Пересоберите административную панель и очистите кэш:
   `bin/build-administration.sh`
   `bin/console cache:clear`

   Совет: с флагом `SHOPWARE_ADMIN_BUILD_ONLY_EXTENSIONS=1` сборка пропустит ядро Shopware и пересоберет только установленные расширения, что значительно быстрее:
   `SHOPWARE_ADMIN_BUILD_ONLY_EXTENSIONS=1 bin/build-administration.sh`

## Использование

1. Откройте административную панель Shopware.
2. Перейдите в **Настройки → Расширения → shopware-reorder-insights** для настройки видимости блоков.
3. Откройте любую карточку **Товара**: перейдите на вкладку **Заказы**, чтобы посмотреть историю заказов этого товара.
4. Откройте профиль **Клиента**, чтобы увидеть всю историю его покупок.
5. В **Storefront** покупатели могут перейти в **Мой кабинет → Купленные товары** для быстрого повторного заказа.
